
# 01 MNIST 讲师授课脚本

> 学员课前阅读材料：`01_mnist/README.md`
> 建议时长：70 分钟

## 一、课堂目标（讲师心里默念，不投影）

学员下课后能：

1. 面对任何一张 28×28 手写数字图，说清楚模型输出的是什么、损失函数在比较什么、优化器改了什么。
2. 在无笔记的情况下画出训练循环的五步框图。
3. 独立区分三个常见误解：输出是概率、保存的权重包含模型结构、验证集可以替代测试集。
4. 有动力去跑第一个实验并记录观察。

## 二、开场钩子（0-8 分钟）

**投影一句话**：
> “写一个程序，判断一张图片里的手写数字是几。给你 100 张图片，你怎么写？”

- 让学员讨论 2 分钟，典型回答：“if 某个像素>阈值 then …” 或者 “用 OpenCV 找轮廓”。
- 讲师追问：“如果图片的角度、粗细、位置都在变，你的规则能撑多久？”
- 引出结论：**传统编程是从数据 + 规则 → 答案；机器学习是从数据 + 答案 → 规则（模型参数）。**

此时板书左侧写下：`数据 + 答案 -> 规则`。宣布：这堂课就是亲手实现一次这个过程。

## 三、建立骨架（8-25 分钟）

**板书设计（在黑板/白板上逐行写出，边写边讲）**

```
x [B,1,28,28]
  ↓  CNN
logits [B,10]
  ↓  CrossEntropyLoss(logits, y)
loss 标量
  ↓  loss.backward()
gradients
  ↓  optimizer.step()
更新后的参数
```

每写一行，用生活类比：

- **logits**：“考试后你每道题的原始得分，不是年级排名百分比。”
- **loss**：“你离年级第一差多少分。”
- **backward**：“分析你这张卷子每一题贡献了多少差距。”
- **optimizer.step()**：“根据错因分析，针对性刷题，下次考更好。”

强调核心：“这五步是骨架，以后做 GPT、微调大模型，也是这个循环，只是 `CNN` 换成 `Transformer`，loss 换一种而已。”

## 四、代码走读（25-40 分钟）

**要求学员打开两个文件：`model.py` 和 `train.py`**

### 4.1 model.py（5 分钟）
- 带着走一遍 `forward`：两个卷积+池化让 28→14→7，展平，两个全连接。
- 在 `self.fc2` 后面停住，**提问**：“为什么这儿没有 Softmax？” 让学员回想板书里的 logits。

### 4.2 train.py（10 分钟）

- 指出设备选择、DataLoader、模型实例化、criterion 和 optimizer。
- 进入训练循环，带领学员逐行找出 `optimizer.zero_grad()` → `outputs = model(images)` → `loss = criterion(outputs, labels)` → `loss.backward()` → `optimizer.step()`，让他们用笔在代码旁标上 1~5 步骤的注释。

关键停顿：“谁能告诉我，如果我不写 `zero_grad()` 会发生什么？”（梯度累加，相当于多人批卷总分累加到一起，更新会错乱。）

## 五、认知误区辨析（40-55 分钟）

**投影三个误区，逐个击破，每个都先问“对还是错”**

| 误区 | 错误表现 | 正确理解 | 引导方式 |
|------|----------|----------|----------|
| 1. 模型输出概率 | “最后输出 0.8 就是概率” | 输出是 logits，损失函数内做 softmax。 | 问：`argmax(logits)` 和 `argmax(softmax(logits))` 一样吗？一样，但是数值范围完全不同。 |
| 2. .pt 文件能用 | “我把权重发朋友就能跑” | 必须有模型类定义和预处理代码。 | 现场把 `.pt` 文件拷贝到另一台“干净”环境，加载报错演示。 |
| 3. 验证集代表最终水平 | “我的模型准确率 99% 了，可以上线” | 验证集用于调参，测试集才能报告最终能力。 | 追问：如果你用验证集反复调参，100 次后，你还能说它代表未知数据吗？ |

每个误区击破后，板书关键词留存，下课前回顾。

## 六、实验驱动（55-65 分钟）

**不会当堂全程训练，而是用提前录好的结果展示对比。**

分别展示：

- Dropout=0 vs 0.5 的训练/验证曲线
- batch_size=8 vs 64 的 loss 震荡对比

每个对比先让学员提出假设，再展示图表。最后抛出一个当堂无法立即回答的问题：“如果我们的模型保存的是 best accuracy 时的权重，而不是最后一个 epoch，验证和测试的差距会变小吗？” → 这就是他们的课后实验。

## 七、收束与预告（65-70 分钟）

- 快速重复板书上的五步骨架，请两位学员用口语串讲一遍。
- 明确课后任务：从 README 的四个实验里至少完成两个，并记录观察。
- 预告下一课：CIFAR-10，数据变彩色、变复杂，模型将如何进化？核心骨架不变，但会引入更多正则化和更好的分类头。

**结束语**：“你现在已经拥有了整个系列最重要的认知资产——训练闭环。接下来每一课，不过是给这个骨架换上不同的器官。”
